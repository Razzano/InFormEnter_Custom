# To Install InFormEnter-Custom

1. Create a new folder and name it, for an example, InFormEnter-Custom
2. Un-zip the contents in this Zip Folder into newly created folder
3. Recommended placement of folder C:\Users\username\AppData\Local\ or Windows Documents folder
4. Go to Browser Extensions Page and enable Developer mode
5. Click on "Load unpacked" button and navigate to the newly created folder and "Select Folder"
6. InFormenter+ App will be listed as an Unpacked extension
7. Complete with translations in: ar, bn, cs, da, de, el, en, es, fa, fi, fr, he, hi, id, it, ja, ka, ko, ms, nl, pl, pt_BR, ro, sv, ta, th, tr, uk, ur, vi, zh_CN

NOTES:

1. InFormEnter-Custom is a standalone version. Any modifications/edits made to the files within this version, as changes to the original InFormEnter+ files will not have any affect, will have immediate effect.

2. Disable Marker Icon While Retaining Context-Menu Functionality: Edit the first block of content.js to prevent the InFormEnter marker icon from appearing on specified input fields while preserving their right-click context-menu functionality.
